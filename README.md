## ⚡ Quick Install via Homebrew

The easiest way to install and keep EasyMac Cleaner updated:

```bash
brew install --cask easymac-cleaner
```

> 💡 **Tip**: To update in the future, simply run `brew upgrade --cask easymac-cleaner` or use the built-in Sparkle autoupdater.

Prefer direct installation? Download the signed & notarized `.zip` archive from our [Official Website](https://martiancat.space) or from the [Releases](https://github.com/MartianCatBR/easymac-cleaner/releases) page.

## ✨ Comprehensive Feature Suite

EasyMac Cleaner is structured into three dedicated modules designed to keep your Mac running fast, clean, and private:

### 🧹 1. Cleanup
- **⚡ Accumulations**: Safely reclaims gigabytes of disk space by eliminating orphaned user caches, application temporary data, diagnostic crash logs, and Xcode derived data.
- **🗑️ Trash & Downloads**: Smart rules and age filters to clean forgotten Trash items and stale installer downloads.
- **📦 Large Files**: High-speed disk analyzer to identify, sort, and inspect space-consuming giants.
- **👥 Duplicate Files**: Content-aware hash scanning to discover exact file duplicates with side-by-side preview and safe removal.
- **🕰️ Old Files**: Uncovers documents and archives untouched for months or years to help you declutter your drive.
- **🔒 Traces & Privacy**: Wipes browsing histories, cookies, download records, and cache sessions across Safari, Chrome, Brave, Edge, and Firefox.
- **⚙️ Lipo**: Universal binary stripper that removes redundant processor architecture slices (e.g., removing Intel code on Apple Silicon M-series Macs) with automated backup safety.

### 🚀 2. Optimization
- **🚀 Login Items**: Disable hidden startup apps and background helpers to accelerate your Mac’s boot speed.
- **⏱️ Scheduled Tasks**: Inspect and manage third-party `LaunchDaemons` and `LaunchAgents` running in the background.
- **📊 Storage**: Interactive storage visualizer that diagnoses volume health and recovers macOS purgeable space.

### 🛠️ 3. Tools
- **🎛️ System Monitor**: Lightweight, real-time menu bar HUD displaying live CPU load, Memory pressure, Disk read/write speeds, and temperature.
- **🧠 Free RAM**: Instantly reclaims inactive memory and flushes memory caches using safe native kernel calls.
- **🔧 Maintenance**: Rebuild Spotlight indexing, flush DNS caches, repair disk permissions, and run routine system maintenance scripts.
- **💥 Shredder**: Permanent, multi-pass cryptographic file destruction ensuring sensitive data cannot be recovered by forensic tools.
- **☁️ Optimize Cloud**: Frees local storage by clearing cached offline files from iCloud Drive, OneDrive, Google Drive, and Dropbox without deleting cloud originals.
- **🌐 Server & NAS Cleanup**: Removes hidden `.DS_Store`, AppleDouble files, and network metadata junk from SMB, NFS, and AFP shares.
- **🔋 Optimize Battery**: Deep energy diagnostics, power management tweaks, and battery longevity insights for MacBook models.

## 🛡️ Security & Privacy First

- **Apple Notarized & Signed**: Digitally signed with an official Apple Developer ID and notarized through Apple's automated malware scan ticket.
- **Zero Invasiveness**: Operates strictly within macOS security guidelines. Does **not** require disabling System Integrity Protection (SIP) or installing root kernel extensions.
- **Your Data Stays on Your Mac**: EasyMac Cleaner runs 100% locally. Your files, documents, and personal traces are never uploaded or transmitted.
- **📜 Transparent Privacy Policy**: Full details regarding our strict zero-telemetry default and optional metrics can be reviewed at [**martiancat.space/privacy.html**](https://martiancat.space/privacy.html).
